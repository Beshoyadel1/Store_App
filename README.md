# Store App

An online store demo app built with Flutter: product catalog, categories and product detail pages with a clean shopping UI.

## Features

- Product catalog organized by category (avatars, cars and more)
- Product details with image, price and Buy flow
- Favorites (wishlist hearts)

## Tech Stack

- Flutter & Dart
- REST API for product data
