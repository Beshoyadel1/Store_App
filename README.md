# Store App

An online store demo app built with Flutter: product catalog, categories and product detail pages with a clean shopping UI.

## Features

- Sign-in screen
- Product catalog organized by category
- Product details with images, price and description

## Tech Stack

- Flutter & Dart
- REST API for product data
